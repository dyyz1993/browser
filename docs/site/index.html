它能做什么

🕸 SPA 渲染

执行页面 JavaScript，等待动态内容加载完成，从最终 DOM 提取数据（不是原始 HTML）。

🛡 通过反爬验证

自动通过 xcancel 等站的浏览器验证：PoW 工作量证明、浏览器指纹、ECIES 加密上报、行为序列。

🔐 Chrome 同形 TLS

BoringSSL（Chromium 同源库）+ H2 连接复用，传输层指纹与 Chrome 一致。

📦 资源批量下载

--save-assets 按域名/后缀/glob 匹配页面资源（图片/字体/视频）批量落盘。

🖥 多格式输出

text / markdown / html / links / JSON 五种格式，按需提取。

🔌 CDP Server

browser cdp --port 9222 启动后 Puppeteer/Playwright 可直接连接。

一键安装

$ curl -fsSL https://raw.githubusercontent.com/dyyz1993/browser/main/install.sh | sh

自动检测操作系统（macOS/Linux）、CPU 架构（x86_64/arm64）、glibc 版本。老 Linux 自动附带 portable-glibc。

快速上手

基本用法

# 拉取页面（等 JS 执行完再提取）
$ browser fetch https://react.dev/ --format markdown
 
# 截图
$ browser render-url https://example.com/ --screenshot out.png

通过反爬验证（xcancel）

# 全功能版（需 --features "v8,chrome-tls" 编译）+ 代理
$ browser fetch https://xcancel.com/elonmusk \
    --js-engine v8 \
    --proxy http://127.0.0.1:7890 \
    --format markdown

批量下载资源

# 按域名下载全部图片
$ browser fetch https://xcancel.com/elonmusk \
    --save-assets "pbs.twimg.com" \
    --save-dir ./images
 
# 按 glob 匹配（400x400 规格的头像）
  --save-assets "**/profile_images/**_400x400.jpg"

反爬能力

验证类型原理状态
PoW 工作量证明JS 解题（SHA-256 前缀匹配）✅ 自动通过
浏览器指纹V8 引擎 + 100+ 项 API 对齐 Chrome✅ 自动通过
TLS 指纹BoringSSL（Chromium 同源库）✅ 需要 chrome-tls
行为序列favicon / Sec-Fetch / priority 请求头✅ 自动通过
验证码图片验证码❌ 不处理

全功能版需要 --features "quickjs,v8,chrome-tls" 编译。国内服务器需要 --proxy 指定代理。

🎯 体验难度阶梯

从易到难四个关卡——每关都是真实站点，点击卡片复制命令直接跑。第 4 关需要通过实时反爬验证才能拿到数据。

● L1 入门 · 静态页

example.com——最简单的开始，体验 fetch → 提取 → markdown 输出。

$ browser fetch https://example.com/ --format text

✓ 输出 "Example Domain" 正文，全程 <1 秒、内存 ~15MB

● L2 进阶 · SPA 动态渲染

react.dev——React 官网，纯 JS 渲染。curl 只能拿到空壳，我们的引擎等 React 执行完再提取。

$ browser fetch https://react.dev/ --format markdown

✓ 覆盖率约 91%（对标 Chrome），内存 ~25MB

● L3 困难 · 重 JS + 动态加载

weibo.cn 手机版——需要登录态才能看到个性化时间线（--cookie-file 导入）。

$ browser fetch https://weibo.cn/ \
  --cookie-file weibo_cookies.tsv --format text

✓ 实测：无 cookie=302 踢游客页；带 cookie=登录首页（21MB 内存）

● L4 地狱 · 实时反爬验证

xcancel.com——PoW 工作量证明 + 100 项浏览器指纹 + ECIES 加密上报。需全功能版 + 代理。

$ browser fetch https://xcancel.com/nim_lang \
  --js-engine v8 --proxy http://127.0.0.1:7890 \
  --format markdown

✓ 实测：自动解 PoW（30 题）→ 指纹加密上报 → verify 200 → 拿到推文（16.5KB）

L4 通关实测数据（真站，挑战开启状态）

指标数值
PoW 解题30 道题全对（Worker 真实计算）
指纹上报100+ 项全对齐 Chrome（maths 逐位一致）
加密链路ECDH P-256 → HKDF → AES-GCM（纯 Rust/JS 实现）
verify 结果200 OK
内存 / 耗时96MB / 13 秒（Mac）· 44MB / 19 秒（2 核云机）

从源码编译

# 轻量版（默认，QuickJS，10MB）
$ cargo build --release -p browser-cli
 
# 全功能版（V8 + Chrome TLS，60MB，需要 cmake）
$ cargo build --release -p browser-cli --features "quickjs,v8,chrome-tls"
