## M7.3 — 异步 JS（Promise / setTimeout / microtask）（P2）

**目标**：让真实 SPA 的 `fetch().then()`、`setTimeout(fn, 0)`、`useEffect` 能跑。

### 决策点（M7.3 开工前必须答）

**Q：继续用 boa_engine 还是切 deno_core？**

| 选项 | boa 0.20 | deno_core |
|------|---------|-----------|
| Promise 支持 | ✅ 但 API 弱 | ✅ 完整 |
| setTimeout | 需自己实现 microtask 调度 | ✅ 内置 |
| 跨平台 | ✅ 纯 Rust | ✅ 但需 V8 binary |
| 学习价值 | 高（手写 microtask loop） | 低（V8 黑盒） |
| 包大小 | ~2MB | ~50MB |

**推荐：M7.3 先在 boa 上手写 microtask loop**（学习价值 + L1 自研原则），如果做不下去再切 deno_core（fallback）。

### 子任务（boa 路线）

| # | Step | 验收 | 状态 |
|---|------|------|------|
| M7.3.1 | `js-runtime/src/microtask.rs`：`MicrotaskQueue`，存 JsFunction | 单测：enqueue + drain 跑 callback | ⚪ |
| M7.3.2 | `js-runtime`：`__queueMicrotask(fn)` 桥 | 单测：JS 调用 → Rust 跑 fn | ⚪ |
| M7.3.3 | script 执行结束后自动 drain microtask（在 `execute_scripts` 末尾） | e2e：queueMicrotask 写 DOM → 在 layout 前生效 | ⚪ |
| M7.3.4 | `setTimeout(fn, ms)`：基于 `std::time::Instant` + 事件循环 | 单测：setTimeout 0 → 立刻跑；100ms → 100ms 后跑 | ⚪ |
| M7.3.5 | `Promise.resolve().then(fn)` → 内部用 microtask 实现 | e2e：Promise.then 改 DOM 生效 | ⚪ |
| M7.3.6 | 异步 fetch：`__fetchAsync(url).then(fn)` 桥（替代 M4 同步 `__fetchSetBody`） | e2e：fetch + then + 改 DOM | ⚪ |
| M7.3.7 | 真实 SPA fixture：模拟 React useEffect（setTimeout 0 + fetch） | e2e：fixture 跑通 | ⚪ |

**Acceptance**：
```bash
cargo test --workspace                          # ~215 passed
cargo run -- render-script tests/fixtures/spa-promise.html
  → 输出含 Promise.then 后改的 DOM
```

**Fallback**：如果 boa microtask 实现不靠谱，**M7.3 改为切 deno_core**（替换整个 `js-runtime` crate 内部，外部 bridge API 不变）。

## M7.4 — 真实字体（Unicode + 抗锯齿）（P3）

**目标**：替换 5x7 bitmap，支持中文 + 多字号 + 抗锯齿。

### 决策点

**Q：cosmic-text 还是 fontdue？**

| 选项 | cosmic-text | fontdue |
|------|-------------|---------|
| 代码量 | ~2w 行 | ~1w 行 |
| 功能 | 文本布局 + shaping + 折行 + emoji | 仅光栅化 |
| 学习价值 | 中（封装好） | 高（自己接 layout） |
| 复杂度 | 高 | 中 |

**推荐：fontdue**（更接近 L1 自研原则，自己拼 layout；cosmic-text 太"成品"）。

### 子任务（fontdue 路线）

| # | Step | 验收 | 状态 |
|---|------|------|------|

| M7.4.4 | `gui/src/paint.rs`：把 alpha mask blend 到 softbuffer ARGB buffer（手写 alpha blend） | 单测：alpha=128 → 半透明 | ⚪ |
| M7.4.5 | 替换 `bitmap_font.rs` 使用：所有字符渲染走 fontdue 路径 | demo.html 渲染含抗锯齿 | ⚪ |

## Commit 流程规则

- **每个 sub-step = 1 commit**（M7.1.1 ~ M7.6.3 共约 35 个 commit）
- **conventional commits**：`feat(css-engine): margin shorthand parsing (M7.1.1)`
- **每个 commit 前必须 pass**：`cargo fmt --check && cargo clippy -D warnings && cargo test`
- **snapshot 更新单独 commit**：`test(snapshots): regenerate goldens for M7.1 margin changes`
