## 踩坑记录

### 1. `html5ever` 0.27 API 漂移
- **现象：** 用 `html5ever::tree::TreeSink` 编译报"could not find `tree` in `html5ever`"
- **根因：** 0.27 把 `TreeSink` 迁到了 `markup5ever::interface::tree_builder`，trait 方法签名也变了（`&self` → `&mut self`，`Cow<str>` → `StrTendril`）
- **解决：** 参考 html5ever 0.27 自带 example `print-tree-actions.rs`，用 `QualName::expanded()` 返回 `ExpandedName<'static>` 而不是自己拼
- **教训：** 选第三方 crate 版本时，先看它仓库的 example，不要靠过时博客

### 2. `ExpandedName` 借用问题
- **现象：** `ExpandedName { ns: &ns!(html), local: LocalName::from(...) }` 编译报"cannot return reference to temporary"
- **根因：** `ns!(html)` 返回的不是 `'static`，且 `LocalName::from(...)` 是临时值
- **解决：** 在 Sink 里维护 `HashMap<NodeId, QualName>`，`elem_name` 通过 `QualName::expanded()` 返回 `'static` 引用
- **教训：** `markup5ever` 的设计就是希望调用方 cache `QualName`，这是标准用法

### 3. `pretty_print` snapshot 字符串语法
- **现象：** `"Document\n\` 多行字符串里 leading 空白被 Rust 续行语法吃掉
- **根因：** `\` 续行时编译器会跳过下一行的 leading whitespace
- **解决：** 改用 `[...].join("\n")` 数组拼接
- **教训：** snapshot 测试用 vec/array join 比 `\` 续行更可靠

### 4. `assert_cmd` cwd 行为
- **现象：** CLI 集成测试里 `parse "crates/..."` 报"No such file"
- **根因：** `assert_cmd` 子进程 cwd = crate root，不是 workspace root
- **解决：** 用相对路径 `tests/../../html-parser/...`
- **教训：** 集成测试涉及 fixture 路径时，从 crate 自己的相对路径算起

### 5. fmt 自动重排单行 enum
- **现象：** 我写的多行 `Doctype { name: String }` 被 rustfmt 强制拍成单行
- **根因：** rustfmt 默认 `enum_variant_width_threshold` 较小
- **解决：** 接受 rustfmt 风格，不要 fight the formatter
- **教训：** 写代码前先 `cargo fmt --check` 看一眼别人格式

## 经验沉淀

### 技术经验
- `html5ever` 0.27 + `markup5ever` 0.12 的桥接模式：`Sink` + `RefCell`-free 设计
- arena DOM 比 `Rc<RefCell>` 容易写得多——M1.2 没遇到任何借用 panic
- `tokio::runtime::Builder::new_current_thread` 适合 CLI 这种不需要并发的场景
- `anyhow::Error` 用 `eprintln!("error: {e:#}")` 打印完整错误链，对 CLI 调试友好

### 工程经验
- M1.0 的 CI 配置（`-D warnings` + fmt check）从第一天就避免了大量风格争议
- fixture 文件纳入 git 是对的——`example.com.html` 抓回来后测试就完全离线
- 一步一 commit 让回滚和心理压力都小很多
- ADR-0001 在写代码前就定了 arena 方案，省了至少半天的反复

### 流程经验
- "executor 在每步真跑 4 条验收命令"这一条对质量提升巨大——多次发现 fmt / clippy fail，写完代码 ≠ 完成
- 用 `awk` 统计 `cargo test` 通过数比肉眼看更准
- "写代码 → fmt 自动跑 → clippy → test" 这个顺序不能颠倒
