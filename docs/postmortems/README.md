# Postmortems

每个里程碑结束后写一份复盘，固化经验。

## 命名规则
`MN.md`，例如 `M1.md`、`M2.md`。

## 模板

```markdown
# Milestone N 复盘

- **日期：** YYYY-MM-DD
- **耗时：** 计划 X 周，实际 Y 周

## 目标回顾
本里程碑计划达成的目标。

## 完成情况
- ✅ 完成的 step
- ⏸ 推迟的内容（含原因）
- ❌ 放弃的内容（含原因）

## 踩坑记录
按时间顺序列出。每条：
- 现象
- 根因
- 解决
- 教训（一句话）

## 经验沉淀
- 技术经验
- 工程经验
- 流程经验

## 下一里程碑准备
- 风险点
- 待确认决策
```
