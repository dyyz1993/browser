| 指标 | 值 |

## 剩余 2 项逐项分析

1. **`sig.automation.cdp` ours=false vs chrome=true**：oracle 伪影。基准 Chrome
   由 CDP 驱动采集，自身命中 cdp 探针。真实用户 Chrome 为 false——我们的值
   才是"通过"形态。不可修复也不需修复（除非换采集方式重采基准）。
2. **`sig.graphics.canvas.canvasFingerprint` ours=-650ed7e0 vs chrome=-240ae8ee**：
   canvas 真像素渲染 hash（M94 canvas2d.rs：超采样 AA + fontdue 文本）。
   Skia 与 fontdue 的字形 hinting/AA/亚像素定位差异必然产生不同像素 →
   不同 hash。**hash 一致 = 像素级一致 = Skia 级渲染 = M80 明确非目标**。
   服务端不可能将 canvas hash 当作硬性匹配（它是机器指纹，GPU/字体/缩放
   都会变），族群评分更可能用布尔/形状信号（webdriver/cdp/etsl/TypeError
   ——现全部对齐）。

1. **`v8::icu::set_default_locale("zh-CN")`**（engine_v8.rs init）：对齐 shim
   navigator.language 常量——Chrome 从浏览器语言推导 Intl locale；修复
   `Intl.DateTimeFormat().resolvedOptions().locale` en-US → zh-CN。
